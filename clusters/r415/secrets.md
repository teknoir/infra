Names only; never values. Collected read-only on 2026-11-24 with
`kubectl --context r415 get secrets -A` (83 Secrets, excluding Helm release records and ServiceAccount tokens).
CI v4 plan: `plans/cicd/proposal-v4.md` section 6. Update this file when a Secret is added or its minter changes.
